Helldivers 2 Slopinator

A Loadout Randomizer Fan-Project

Faction
Lock slots

Pin specific gear and randomize the rest. Type a name or nickname (e.g. liberator, eat-17). Locks override the slot rules (backpack count, support caps, etc.). If your locks make some guarantees impossible, the loadout is still built and the missed guarantees are listed above it.

Rules

Default rules

What every loadout is checked against. Switch one off and the randomizer stops enforcing it. When a build can't meet everything, higher-priority rules are protected first. The plain "how many" defaults (Anti-Tank, Vehicle, Eagle and so on) are the first rows under Additional rules, where you can change the numbers.

Additional rules

How many items with a tag the whole loadout must have. The dimmer rows are the system defaults. To change one, add a rule for the same tag (it replaces that number); remove one with the ×. At least and at most on the same tag make a range. At most 0 / exactly 0 bans the tag.

Tick what you own; the randomizer only rolls owned gear. Block takes an item out of the pool without un-owning it. Base Game gear is always owned (you can still block it). Saved in this browser only.

Tick which factions each item is recommended against: Terminid, Automaton, Illuminate. All three ticked works against anything; with none ticked an item only rolls when the faction is Any. An item you've changed gets a coloured edge and a ↺ button to put it back.
